# LeetCode

Bộ notebook Jupyter (.ipynb) tiếng Việt giảng giải bài LeetCode cho người nhập môn, theo cẩm nang
`huong_dan_phong_cach_day_code_ipynb.pdf`. Danh mục ID và độ khó của toàn bộ bài nằm trong
`LeetCode_Danh_Muc_4114_Theo_Do_Kho.pdf`.

Mỗi notebook đi theo cùng một trình tự: đề bài → kiến thức nền → 3–5 cách giải từ đơn giản đến tối ưu →
mô phỏng từng bước (bảng + hàm `trace_*`) → code `class Solution` + test (kể cả đối chiếu chéo ngẫu nhiên) →
vì sao đúng / độ phức tạp → lỗi thường gặp → mẹo nhận dạng & bài liên quan → 4–6 bài tập (TODO + gợi ý 3 mức) →
đáp án ở cuối → template và checklist. Mọi notebook đều chạy sạch từ trên xuống trên kernel Python 3 mới và đã lưu sẵn output.

Bài Premium: đề bài viết theo hiểu biết về bản LeetCode (không mở trực tiếp được), nên đối chiếu lại nếu có tài khoản Premium.
Bài SQL: dạy bằng `sqlite3`, lời giải cuối viết theo cú pháp MySQL của LeetCode.
